# Resources

Shared assets of the SPARC Community: logos and profile picture files, maintained by the community.

This repository is the single place for general community resources. SPARC Community members can take files from here instead of keeping their own copies.

## Contents

```
logos/              SPARC Community logo
profile-pictures/
  custom/           custom profile pictures made for individual students
  template/         base template for new profile pictures
```

| Path | Description |
| ---- | ----------- |
| `logos/sparc_community_logo.svg` | Official SPARC Community logo |
| `profile-pictures/template/cat_template_pfp.svg` | Cat template, the starting point for a new profile picture |
| `profile-pictures/custom/` | Finished custom profile pictures, one file per student |

All assets are SVG files.

## Usage

Clone the repository:

```bash
git clone https://github.com/sprac-ch/resources.git
```

Or link a single file directly from `main`:

```
https://raw.githubusercontent.com/sprac-ch/resources/main/logos/sparc_community_logo.svg
```

### Naming convention

Custom profile pictures are named after the student's handle:

```
student_<handle>_pfp.svg
```

If one handle has several pictures, a two-digit counter is appended: `student_<handle>_pfp_01.svg`, `student_<handle>_pfp_02.svg`.
